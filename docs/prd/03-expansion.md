# PRD 03. 확장 기능

작성일: 2026-06-08

## 목적

이 문서는 `nado` MVP 이후 검토할 확장 기능을 정리한다. 확장 기능은 MVP의 사용 패턴, 비용, 학습 효과, 개발 리소스를 확인한 뒤 우선순위를 다시 정한다.

## 확장 원칙

- MVP의 핵심 가치인 "프롬프트 없이 정해진 독해 flow 제공"을 해치지 않는다.
- 분석 품질보다 기능 수를 늘리는 방향을 피한다.
- 비용이 큰 기능은 사용량 제한, 캐싱, 유료 정책과 함께 검토한다.
- 웹, 모바일 앱, 데스크톱 앱이 같은 API 계약을 공유한다는 원칙을 유지한다.
- 사용자의 원문 영어 문장 저장은 명확한 동의와 목적이 생기기 전까지 피한다.

## 확장 후보

### 긴 글 분석

목표:

- 500자를 넘는 글을 문단 또는 문장 단위로 나눠 분석한다.

주요 요구사항:

- 긴 입력을 자동으로 문장/문단 단위로 분리한다.
- 한 번에 너무 긴 분석 결과를 보여주지 않는다.
- 사용자가 보고 싶은 문장 또는 문단을 펼쳐서 본다.
- 비용 보호를 위해 분석 단위를 제한한다.

비고:

- MVP에서는 제외한다.
- 공식문서 리더와 결합될 수 있다.

### 공식문서 리더

목표:

- 개발 문서, 블로그 글, 기술 문서의 짧은 구간을 독해하기 쉽게 만든다.

주요 요구사항:

- URL 또는 텍스트 일부를 입력받는다.
- 문서 전체를 무제한 분석하지 않는다.
- 문장별 구조 분석과 용어 저장 흐름을 유지한다.
- 코드 블록과 일반 문장을 구분한다.

비고:

- 공식문서 전체 자동 크롤링은 초기 확장 범위에 포함하지 않는다.

### 브라우저 확장 또는 사이드 패널

목표:

- 사용자가 웹에서 읽다가 모르는 문장을 바로 분석할 수 있게 한다.

주요 요구사항:

- 선택한 영어 문장을 `nado` 분석 API로 보낸다.
- 로그인한 사용자는 단어를 저장할 수 있다.
- 확장 안에서도 원문 저장 정책과 AI 전송 안내를 유지한다.

비고:

- MVP 이후 사용자가 웹사이트 방문과 복사/붙여넣기를 귀찮아한다고 판단되면 우선순위를 올린다.

### 앱 출시

목표:

- Expo 앱을 TestFlight, Google Play internal testing, App Store, Google Play로 확장한다.

주요 요구사항:

- 앱 환경의 Google 로그인 안정화
- API base URL 환경 분리
- 앱 권한과 개인정보 안내 정리
- 기본 QA 체크리스트 작성

비고:

- MVP 목표는 Expo 실행 가능 상태다.

### 데스크톱 고급 기능

목표:

- Tauri 데스크톱 앱만의 생산성 기능을 제공한다.

후보 기능:

- 클립보드에서 영어 문장 가져오기
- 글로벌 단축키
- 최근 분석 로컬 캐시
- 데스크톱 알림
- 오프라인 단어장 보기

비고:

- 로컬 DB와 오프라인 모드는 MVP 이후로 둔다.

### 단어장 검색과 필터

목표:

- 단어장이 커졌을 때 사용자가 저장 항목을 쉽게 찾게 한다.

주요 요구사항:

- 단어/표현 검색
- word/phrase 필터
- 최근 저장순/최근 업데이트순 정렬
- 여러 의미가 있는 항목 표시 유지

비고:

- MVP에서는 단어장 목록과 삭제만 제공한다.

### 예문 생성

목표:

- 저장한 단어/표현을 더 잘 기억할 수 있게 예문을 제공한다.

주요 요구사항:

- 저장 항목 기준으로 짧은 예문 생성
- 한국어 해석 제공
- 사용자의 수준에 맞는 쉬운 예문 우선

비고:

- OpenAI 비용이 증가할 수 있으므로 사용량 제한 또는 캐싱과 함께 검토한다.

### 간격 반복 학습

목표:

- 저장한 단어를 장기 기억에 도움이 되는 복습 시스템으로 확장한다.

주요 요구사항:

- 정답/오답 기록
- 다음 복습일 계산
- 복습 기록 저장
- 오늘 복습할 항목 목록

비고:

- MVP 복습은 정답/오답 채점 없는 랜덤 플래시카드다.

### 분석 히스토리

목표:

- 사용자가 이전 분석 결과를 다시 볼 수 있게 한다.

주요 요구사항:

- 분석 결과 저장 여부를 사용자가 명확히 선택한다.
- 원문 문장 저장에 대한 개인정보 안내를 제공한다.
- 사용자는 저장한 분석을 삭제할 수 있다.

비고:

- MVP에서는 전체 분석 히스토리와 원문 영어 문장 저장을 제외한다.

### 비용 정책과 수익화

목표:

- 운영 비용이 커졌을 때 지속 가능한 정책을 만든다.

후보:

- 제한된 무료 분석
- 유료 플랜
- 크레딧 시스템
- 사용자 개인 API key 연결

비고:

- MVP에서는 수익화를 구현하지 않는다.
- 무료 분석 횟수는 MVP 동작 후 비용, 응답 속도, 사용 패턴을 보고 결정한다.

## 우선순위 가이드

MVP 이후 우선순위는 아래 기준으로 정한다.

1. 사용자가 실제로 불편해하는 반복 작업인가
2. 영어 독해 실력 향상에 직접 도움이 되는가
3. AI 비용이 감당 가능한가
4. 웹, 모바일, 데스크톱 중 어디에 먼저 적용할지 명확한가
5. 포트폴리오에서 제품 안정성, 검증, 성능, 접근성을 보여주는 데 도움이 되는가

## 확장 기능 완료 기준

각 확장 기능은 별도 PRD를 작성한 뒤 구현한다. 각 PRD는 아래 내용을 포함해야 한다.

- 사용자 문제
- 목표 사용자
- 포함 범위
- 제외 범위
- 화면 요구사항
- API 요구사항
- 데이터 요구사항
- 에러 처리
- 비용/보안 고려사항
- 성공 기준
