# PRD 02. 최소 MVP 기능

작성일: 2026-06-08
수정일: 2026-06-09

## 목적

`nado`의 첫 사용자가 영어 한 문장 또는 짧은 문단을 입력하고, 자연스러운 번역과 독해 분석을 받은 뒤, 모르는 단어를 저장하고 복습할 수 있게 만든다.

## 제품 문제

번역기는 의미를 빠르게 알려주지만 사용자가 영어 문장을 어떻게 읽어야 하는지는 충분히 알려주지 않는다. ChatGPT는 도움이 되지만 매번 "번역해줘", "문법도 분석해줘", "중요 단어도 뽑아줘" 같은 프롬프트를 작성해야 한다. `nado`는 이 귀찮음을 없애고 항상 같은 학습 flow를 제공해야 한다.

## 목표

- 로그인 없이 영어 입력을 분석할 수 있다.
- 입력은 MVP 초기 최대 200자로 제한하고, 정규화된 지원 문자 기준으로 검증한다.
- 분석 결과는 단일 기본 분석 flow로 제공한다.
- 자연스러운 한국어 번역을 먼저 보여준다.
- 번역 포인트를 짧게 보여준다.
- 문장별 끊어 읽기, chunk별 직역, 자연스러운 문장 번역, 문법 포인트를 보여준다.
- 원문 속 모든 영어 단어를 선택해서 뜻을 보고 저장할 수 있다.
- 추천 단어/표현은 자동 저장하지 않는다.
- 단어 저장, 단어장, 복습은 Google 로그인 후 사용할 수 있다.
- 단어장은 저장된 모든 뜻과 설명을 기본적으로 보여준다.
- 복습은 정답/오답 채점 없이 플래시카드 방식으로 제공한다.

## 비목표

- 긴 문서 전체 분석
- 공식문서 리더 모드
- 브라우저 확장
- PWA
- Capacitor 또는 React Native WebView wrapper 앱
- 사용자 개인 OpenAI API key 연결
- 결제, 크레딧, 유료 플랜
- 간격 반복 학습
- 정답/오답 채점
- 전체 분석 히스토리 저장
- 단어장 항목에 사용자의 원문 영어 문장 저장

## 핵심 사용자 흐름

### 분석 흐름

1. 사용자가 분석 화면을 연다.
2. 영어 한 문장 또는 짧은 문단을 입력한다.
3. 빈 입력이면 분석 버튼은 비활성화된다.
4. 분석 요청은 정규화된 지원 문자 기준 200자를 초과할 수 없다.
5. 사용자가 분석을 실행한다.
6. 서버가 입력값을 다시 검증한다.
7. 서버가 OpenAI API를 호출한다.
8. 앱은 아래 순서로 결과를 표시한다.
   - 전체 자연스러운 한국어 번역
   - 번역 포인트
   - 문장별 분석
   - 우선 저장 추천 단어/표현
9. 사용자는 문장별 분석 안의 단어를 hover, focus, tap해서 뜻을 확인한다.
10. 사용자가 저장을 누르면 로그인 여부를 확인한다.
11. 비로그인 사용자는 Google 로그인을 안내받는다.
12. 로그인 사용자는 단어/표현을 저장한다.

### 단어장 흐름

1. 사용자가 Google로 로그인한다.
2. 단어장 화면을 연다.
3. 저장한 단어/숙어/표현 목록을 확인한다.
4. 각 항목에는 단어, 타입, 모든 뜻과 설명, 저장 날짜를 보여준다.
5. 사용자는 항목을 삭제할 수 있다.

이미 저장된 단어/표현을 다시 저장하면 새 항목을 만들지 않고 기존 항목의 `meanings`에 뜻과 설명을 병합한다.

### 복습 흐름

1. 사용자가 복습 화면을 연다.
2. 복습 방향을 선택한다.
   - 영어 -> 한국어
   - 한국어 -> 영어
3. 앱이 단어장 항목 중 하나를 랜덤으로 선택한다.
4. 카드는 문제 쪽만 보여준다.
5. 사용자가 카드를 클릭하면 정답을 보여준다.
6. 사용자가 다음 버튼을 누르면 다음 항목으로 넘어간다.
7. 사용자가 끝내기 버튼을 누르면 복습을 종료한다.

## 화면 요구사항

### 공통 UI 원칙

- 웹 MVP 화면은 Storybook에 등록된 디자인 시스템 컴포넌트와 토큰을 우선 사용한다.
- 새 공통 UI가 필요하면 제품 화면에만 바로 만들지 않고 `packages/ui` 컴포넌트 또는 Storybook story로 함께 정리한다.
- Expo Mobile은 같은 시각 규칙을 따르되 React Native에 맞는 컴포넌트로 구현한다.
- 스타일 방향은 깔끔한 생산성 앱 느낌과 읽기 편한 학습 도구 느낌을 유지한다.

### 분석 화면

- 첫 화면이다.
- 로그인 없이 사용할 수 있다.
- 입력창은 하단 고정 composer 구조를 기본으로 한다.
- 입력창에는 글자 수 표시와 분석 실행 버튼을 둔다.
- `+` 보조 액션 버튼은 MVP에 포함하지 않는다.
- 분석 모드 선택은 제공하지 않는다.
- 결과 섹션은 기본적으로 펼쳐서 보여준다.

결과 순서:

1. 전체 자연스러운 한국어 번역
2. 번역 포인트
3. 문장별 분석
4. 우선 저장 추천

문장별 분석:

- 원문은 chunk 단위로 나눈다.
- 각 영어 chunk 아래에 직역을 자막처럼 보여준다.
- chunk 사이에는 `/` slash를 표시한다.
- chunk 내부 영어 문장과 직역은 줄바꿈하지 않는다.
- 공간이 부족하면 가로 스크롤을 만들지 않고 chunk 블록 전체가 다음 줄로 내려간다.
- AI는 한 chunk가 너무 길어 화면을 밀어내지 않도록 의미 단위가 유지되는 선에서 더 짧게 끊는다.
- 문장 전체의 자연스러운 번역은 chunk 분석 아래에 제공한다.
- 문법 포인트는 대상 표현, 문법 이름, 쉬운 설명을 구분해 보여준다.
- 웹과 Tauri 데스크톱에서는 단어 hover/focus box를 제공한다.
- 모바일에서는 단어 tap popover 또는 bottom sheet를 제공한다.

### 단어장 화면

- Google 로그인이 필요하다.
- 저장된 모든 뜻과 설명을 기본적으로 보여준다.
- 의미 개수만 표시하지 않는다.
- 검색과 필터는 MVP에 포함하지 않는다.
- 사용자는 자기 단어장 항목을 삭제할 수 있다.

### 복습 화면

- Google 로그인이 필요하다.
- 복습 시작 전에 방향을 선택한다.
- 카드를 클릭하면 정답을 보여준다.
- 정답/오답 채점은 없다.
- 다음 버튼으로 랜덤 항목을 계속 보여준다.
- 끝내기 버튼으로 복습을 종료한다.
- 저장 항목이 1개뿐이면 같은 항목 반복을 허용한다.

## API 요구사항

### `POST /api/analyze`

- 인증은 필요 없다.
- `text`는 필수다.
- trim 후 빈 문자열이면 거절한다.
- 서버는 입력을 NFKC로 정규화한 뒤 Unicode code point 기준으로 글자 수를 계산한다.
- 정규화된 지원 문자 기준 200자를 넘으면 거절한다.
- 보이지 않는 제어/포맷 문자와 지원하지 않는 특수문자는 거절한다.
- 명확히 학습 입력으로 보기 어려운 값은 가능한 범위에서 로컬 규칙으로 거절한다.
- 애매한 입력은 AI가 `not_analyzable` 상태를 반환하게 한다.
- 응답은 구조화된 JSON이어야 한다.

필수 결과 필드:

- `translation`
- `translationExplanation`
- `sentences`
- `sentences[].tokens`
- `sentences[].chunks`
- `sentences[].chunks[].literalTranslation`
- `sentences[].grammarPoints`
- `vocabularyItems`
- `vocabularySuggestions`

### `GET /api/vocabulary`

- 인증이 필요하다.
- 로그인한 사용자의 단어장 항목만 반환한다.

### `POST /api/vocabulary`

- 인증이 필요하다.
- `term`, `type`, `meaning`은 필수다.
- `type`은 `word` 또는 `phrase`다.
- 같은 사용자, 같은 정규화 term, 같은 type이 있으면 기존 항목에 뜻과 설명을 병합한다.
- 사용자의 원문 영어 문장은 저장하지 않는다.

### `DELETE /api/vocabulary/:id`

- 인증이 필요하다.
- 삭제 대상은 로그인한 사용자의 항목이어야 한다.

## 인증 요구사항

- MVP는 Google 로그인만 지원한다.
- 분석은 로그인 없이 사용할 수 있다.
- 단어 저장, 단어장 보기, 단어장 삭제, 복습 시작은 로그인이 필요하다.
- Web, Expo Mobile, Tauri Desktop에서 같은 인증 원칙을 유지한다.

## 사용량과 비용 요구사항

- OpenAI API key는 서버에만 보관한다.
- 브라우저, 모바일 앱, 데스크톱 앱에 OpenAI API key를 노출하지 않는다.
- 입력은 정규화된 지원 문자 기준 200자로 제한한다.
- 빈 입력은 클라이언트에서 분석 버튼을 비활성화한다.
- 서버도 입력 길이와 비정상 입력을 검증한다.
- 비로그인/로그인 사용자 분석 제한은 설정으로 조정 가능해야 한다.
- 정확한 무료 분석 횟수는 MVP 동작 후 비용과 사용 패턴을 보고 결정한다.

## 에러 처리

- 빈 입력: 분석 버튼 비활성화
- 200자 초과 또는 지원하지 않는 문자 포함: 분석 요청 차단, 서버 요청 거절
- 의미 없는 입력: "영어 문장으로 분석하기 어려워요. 한 문장 또는 짧은 문단을 입력해 주세요."
- OpenAI API 실패: "분석 중 문제가 발생했어요. 잠시 후 다시 시도해 주세요."
- 구조화 응답 실패: 서버에서 1회 재시도 후 실패 안내
- 비로그인 저장 시도: Google 로그인 안내
- 빈 단어장: "먼저 분석 화면에서 단어/표현을 저장해 주세요."
- AI 분석 전송 안내: "입력한 문장은 AI 분석을 위해 전송되며, 단어장에는 원문 문장을 저장하지 않습니다."

## 성공 기준

- 사용자가 로그인 없이 200자 이내 영어 문장을 분석할 수 있다.
- 분석 결과가 정해진 순서로 표시된다.
- 별도 분석 모드 값이 요청에 포함되지 않는다.
- 문장별 chunk 직역이 제공된다.
- 원문 속 모든 단어가 저장 가능 후보로 제공된다.
- 추천 단어/표현은 자동 저장되지 않는다.
- 비로그인 사용자가 저장을 누르면 로그인 안내가 나온다.
- 로그인 사용자는 단어를 저장하고 단어장에서 볼 수 있다.
- 중복 저장은 새 항목을 만들지 않고 의미를 병합한다.
- 복습은 랜덤 플래시카드로 동작한다.
- Web, Expo Mobile, Tauri Desktop이 같은 API schema를 사용한다.

## MVP 완료 조건

- 웹 분석 화면이 사용 가능하다.
- API 서버가 분석, 단어장 CRUD, 인증 검증을 처리한다.
- Supabase Auth/Postgres에 사용자와 단어장이 저장된다.
- Expo 앱에서 분석, 단어장, 복습 화면이 실행된다.
- Tauri 앱에서 웹 UI가 실행되고 같은 API를 호출한다.
